## [16:56] TOOLS.md 更新 - 数据获取文档

补充了相机图片获取和物体检测的详细说明：

### 获取图片
- RealSense D455 通过 `RealSenseCapture.get_rgbd()` 获取 RGB-D
- 返回 numpy array，自动保存到指定路径

### 获取物体信息
- YOLO-World 检测，支持任意类别名称
- 结果格式: `[x1, y1, x2, y2, conf, class_id]`
- 类别名称支持空格格式 (`pink plate`) 和多类别 (`orange,lemon`)

### 获取 3D 位置
- 2D 像素 + 深度图 → 3D 坐标
- 或使用 anygrasp SDK 获取抓取位姿
