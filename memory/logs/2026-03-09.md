## 三层服务架构

```
┌─────────────────────────────────────────────────────────────────┐
│  start3.bash - 应用层 (planner.py)                              │
│  语音(Whisper) → 解析(LLM) → 检测(YOLO) → 抓取(Anygrasp)        │
│  模型路径:                                                       │
│    - Whisper: /home/zz/faster-whisper-large-v3                  │
│    - YOLO: /home/zz/ros_proj/erdaiji_ws/src/.../yolov8x-worldv2.pt│
│    - Anygrasp: .../anygrasp_sdk/checkpoint_detection.tar        │
└───────────────────────┬─────────────────────────────────────────┘
                        │ Socket (无协议前缀)
┌───────────────────────┼─────────────────────────────────────────┐
│  start2.bash - Twin规划层 (twin.py:8020)                        │
│  PyBullet仿真: IK求解 → 碰撞检测 → 轨迹插值                      │
│  服务类型: reachability_check, trajectory_generation2           │
└───────────────────────┬─────────────────────────────────────────┘
                        │ Socket (4字节长度前缀 + JSON)
┌───────────────────────┼─────────────────────────────────────────┐
│  start1.bash - ROS层                                            │
│  ├─ arm_75_bringup.py:8010 (机械臂 Socket服务)                  │
│  ├─ inspire_hand_bringup.py:8000 (灵巧手 Socket服务)            │
│  ├─ mount_camera.py (相机节点)                                  │
│  └─ RViz可视化                                                   │
│  ROS Topics: /joint_states, /tf, /tf_static                     │
└─────────────────────────────────────────────────────────────────┘
```

## 核心执行流程 (run_pipeline)

```
┌──────────────────────────────────────────────────────────────────┐
│  主循环 while True                                               │
├──────────────────────────────────────────────────────────────────┤
│  1. 语音输入: get_human_voice_input()                            │
│     - Whisper 转录 → "将橘子放在粉色盘子里"                       │
│                                                                  │
│  2. 语义解析: parser_input()                                     │
│     - LLM/规则解析 → obj="orange", container="pink plate"        │
├──────────────────────────────────────────────────────────────────┤
│  【抓取阶段】for key in [grasp1, grasp2, grasp3]:                │
│  │                                                              │
│  ├─ control_arm(pose_type=key) → 移动到观察位                    │
│  ├─ get_camera_obs() → 获取 RGB + Depth                         │
│  ├─ anygrasp_get_poses() → 生成所有候选抓取点                    │
│  ├─ filtering_pose(class_name=obj) → YOLO语义过滤               │
│  │   └─ 只保留目标物体边界框内的抓取点                           │
│  ├─ transform_anygrasp_pose() → 相机坐标→世界坐标                │
│  │                                                              │
│  └─ for pose in grasping_poses:  # 尝试每个姿态                 │
│       execute_grasping_twin_js_2():                             │
│         ├─ 计算预抓取位 (z-2cm)                                  │
│         ├─ Twin.trajectory_generation2() → 轨迹                 │
│         │   ├─ is_reached=0 → 跳过此姿态                        │
│         │   └─ is_reached=1 → 返回关节轨迹                       │
│         ├─ control_arm(trajectory) → 执行轨迹                   │
│         ├─ control_hand("close") → 闭合灵巧手                   │
│         └─ control_arm(pose_type=key) → 返回观察位              │
│                                                                  │
│  ✅ G5. Successfully completed the grasping task                │
├──────────────────────────────────────────────────────────────────┤
│  【放置阶段】for key in [grasp1, grasp2, grasp3]:                │
│  │                                                              │
│  ├─ control_arm(pose_type=key) → 移动到观察位                    │
│  ├─ get_camera_obs() → 获取 RGB + Depth                         │
│  ├─ get_placing_position(class_name=container)                  │
│  │   ├─ YOLO 检测容器边界框                                      │
│  │   ├─ 计算框内深度中位数 → 3D点                                │
│  │   └─ z += 0.15m (悬停高度)                                   │
│  │                                                              │
│  └─ execute_placement_js():                                     │
│       ├─ Twin.trajectory_generation2() → 轨迹                   │
│       ├─ control_arm(trajectory) → 执行轨迹                     │
│       ├─ control_hand("open") → 张开灵巧手                      │
│       └─ control_arm(pose_type="grasp1") → 返回                 │
│                                                                  │
│  ✅ P5. Successfully completed the placement task               │
└──────────────────────────────────────────────────────────────────┘
```

## 关键代码片段

### 1. 灵巧手控制
```python
hand_config = {
    "close": [50, 50, 50, 400, 360, 0],    # 抓取
    "open": [1000, 1000, 1000, 1000, 1000, 0]  # 释放
}
cmd = {"src": "/left_hand/movement_control", "type": "set", "cmd": hand_config["close"]}
sock.sendall(json.dumps(cmd).encode())
```

### 2. Twin服务请求
```python
config = {
    "target_pose": [[x,y,z, qx,qy,qz,qw], ...],  # 目标位姿列表
    "current_js": [j1,j2,j3,j4,j5,j6,j7],        # 当前关节角(弧度)
    "struct": "left_arm"
}
cmd = {"srv": "twin_inference", "type": "trajectory_generation2", "cnfg": config}
# 返回: {"value": 1, "info": {"trajectory": [[j1..j7], ...], "infos": [...]}}
```

### 3. 坐标变换链
```
AnyGrasp相机坐标 → self_pose_matrix修正 → T_base_to_cam → 世界坐标
                                        → transform_x/y_axis修正
```
