## 代码库重大重构 (下午)

### 重构目标
将输入方式从**文件输入**改为 **stdin JSON 输入**，大幅简化代码结构

### 删除的文件
- ❌ `task_input.py`
- ❌ `input/` 目录
- ❌ `HOW_TO_USE_IT_TO_GRASP/` 文档文件夹
- ❌ `USAGE.md`
- ❌ `run.bash`
- ❌ `READ_before_run.txt`
- ❌ `parser.py` (中文解析器)

### 新增的文件
- ✅ `json_input.py` - stdin JSON 输入解析器
- ✅ `CLAUDE.md` - Claude Code 指导文档

### 核心变化

#### 1. 输入方式
```bash
# 旧方式（已废弃）
./run.bash -o orange -c "pink plate"

# 新方式
echo '{"object": "orange", "container": "pink_plate"}' | python3 planner.py
```

#### 2. planner.py 精简
- 代码量从 40KB 减少到 31KB（减少 30%）
- 删除语音输入支持
- 删除中文解析器
- `run_pipeline()` 改为单次执行，返回布尔值

#### 3. JSON 格式
```json
{
  "object": "orange",        // 必填
  "container": "pink_plate", // 必填
  "direction": "left"        // 可选
}
```

#### 4. 新增映射系统 (json_input.py)
- 物体映射：`orange → orange`, `lemon → lemon`, `bottle → bottle`, ...
- 容器映射：`pink_plate → pink plate`, `green_bowl → green bowl`, ...
- 方位映射：`left → left`, `right → right`, `middle → middle`, ...

### 新的启动流程
```bash
终端1: bash start1.bash  # ROS 服务 (8000, 8010)
终端2: bash start2.bash  # Twin IK 服务 (8020)
终端3: echo '{"object":"orange","container":"pink_plate"}' | python3 planner.py
```

### 优势
✅ 更简洁：代码量减少 30%
✅ 更灵活：支持管道、文件、网络等多种输入源
✅ 更通用：易于集成到 API 服务器、消息队列
✅ 更易测试：直接通过管道输入 JSON
