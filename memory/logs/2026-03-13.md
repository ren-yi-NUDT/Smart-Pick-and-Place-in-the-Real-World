## CLAW-ARM-selftry 项目 (18:55-18:58)

**路径**: `/home/zz/Code/CLAW-ARM-selftry/`

独立编写机械臂控制脚本，不依赖原代码库。

### 学到的通信协议

| 服务 | 端口 | 协议 |
|------|------|------|
| 灵巧手 | 8000 | 纯JSON |
| 机械臂 | 8010 | 4字节大端长度头 + JSON |
| Twin | 8020 | 4字节大端长度头 + JSON |

### 控制命令格式

```python
# 灵巧手
{"src": "/left_hand/movement_control", "type": "set", "cmd": [50,50,50,400,360,0]}  # 抓取
{"src": "/left_hand/movement_control", "type": "set", "cmd": [1000,1000,1000,1000,1000,0]}  # 释放

# 机械臂关节控制
{"srv": "/right_arm/movement_control", "cmd": [
  {"type": "start"},
  {"type": "js", "act": {"J1": 5.8, "J2": -8.9, ...}, "speed": 20, "block": true},
  {"type": "end"}
]}
```

### 完成的脚本

1. **place_bottle.py** - 把瓶子放到默认位置 ✅
2. **wave_hand.py** - 挥手动作 (J1左右摆动±20° × 3次) ✅
3. **wave_v17.py** - 末端画弧挥手 (5点四分之一圆弧 × 4次) ✅
4. **actions/wave.json** - 用户录制挥手动作（默认向左）✅

### 挥手技能（默认向左）

**文件**: `/home/zz/Code/CLAW-ARM-selftry/actions/wave.json`
**回放**: `python3 wave_play.py`
**修改方向**: 只改J1（基座旋转）
- 向左：J1=10.4~17.7
- 向前：J1=40.4~47.7（+30°）
- 向右：J1=70.4~77.7（+60°）

### 关键发现

- **J5 限制 ±178°**: 之前 J5=180° 超出 2°，导致机械臂卡死
- **官方参数**: https://develop.realman-robotics.com/robot/robotParameter/RM75OntologyParameters/
- **奇异点类型**: 4种，需避免
- **timeout**: block=true 时需要足够长的 timeout（10-15秒）
