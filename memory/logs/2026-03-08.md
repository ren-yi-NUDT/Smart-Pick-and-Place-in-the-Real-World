### 配置详情

在 `~/.openclaw/openclaw.json` 中添加了 qwen-portal provider:

```json
"qwen": {
  "baseUrl": "http://192.168.100.27:8034/v1",
  "api": "openai-completions",
  "apiKey": "",
  "models": [
    {
      "id": "/home/tangyijie/sglang/Qwen3-32B-AWQ",
      "name": "Qwen3-32B",
      "reasoning": false,
      "input": ["text"],
      "cost": {"input": 0, "output": 0, "cacheRead": 0, "cacheWrite": 0},
      "contextWindow": 40960,
      "maxTokens": 40960
    }
  ]
}
```

模型别名配置:
```json
"qwen//home/tangyijie/sglang/Qwen3-32B-AWQ": {
  "alias": "Qwen3"
}
```

设置默认模型:
```json
"model": {
  "primary": "qwen-portal//home/tangyijie/sglang/Qwen3-32B-AWQ"
}
```

注意：实际配置中 provider key 为 `qwen-portal`，模型完整 key 为 `qwen-portal//home/tangyijie/sglang/Qwen3-32B-AWQ`

### 认证配置

在 `~/.openclaw/agents/main/agent/auth-profiles.json` 中添加:

```json
"qwen:default": {
  "type": "api_key",
  "provider": "qwen",
  "key": ""
}
```

**关键点**:
- 本地模型无需 API key，但需要配置认证 profile（key 为空字符串）
- provider 名称必须匹配 openclaw.json 中的 provider key
